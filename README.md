# BusinessCalendar

SwiftUI calendar app seeded from [Achieve](https://github.com/velvetfasion-a11y/Achieve), focused on the Boss Calendar schedule experience.

## What’s included

- **Boss Calendar** — month / week / day views with pinch zoom, swipe navigation, and event reminders
- **New event sheet** — categories, durations, important/pinned flags
- Habits, AI Coach, Journal, and Profile from the Achieve foundation (same app shell)

## Open in Xcode

1. Open `Achieve.xcodeproj`
2. Select an iOS Simulator or device
3. Build & Run

Source archive used for this import: `/opt/cursor/artifacts/Achieve.zip` (GitHub `main` at `2f5a7c7`).
